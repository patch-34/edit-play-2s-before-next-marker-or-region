# Play 2s Before Next Marker or Region

[English](README.md) · **Русский**

Переходит к позиции за две секунды до следующего маркера или начала региона. Если транспорт активен (воспроизведение, пауза или запись), перемещение выполняется без явной остановки. Если транспорт остановлен, скрипт перемещает курсор редактирования и запускает воспроизведение.

Не требует js_ReaScriptAPI.

## Установка

### Через ReaPack

Добавьте [каталог Patch34 ReaPack](https://raw.githubusercontent.com/patch-34/patch34-reapack/main/index.xml) через **Extensions → ReaPack → Import repositories…**. Найдите **Play 2s Before Next Marker or Region** в **Extensions → ReaPack → Browse packages**, установите пакет и выполните синхронизацию.

### Вручную

1. В REAPER откройте **Actions → Show action list…**.
2. Выберите **New action → Load ReaScript…**.
3. Укажите файл `Play_2s_Before_Next_Marker_Or_Region.lua`.
4. При необходимости назначьте сочетание клавиш.

## Принцип работы

- **Транспорт активен** (воспроизведение, пауза, запись) — берёт исходную позицию курсора воспроизведения, находит следующий маркер или начало региона и выполняет переход к `next_pos - 2.0s`, не останавливая транспорт.
- **Транспорт остановлен** — берёт исходную позицию курсора редактирования, перемещает его к `next_pos - 2.0s` и запускает воспроизведение.
- Учитываются как маркеры, так и начала регионов. Выбирается ближайшая подходящая позиция **справа** от исходной.
- Если справа нет ни маркеров, ни начал регионов, появляется окно сообщения и дальнейших действий не выполняется.

## Настройка

Длительность предварительного отступа задаётся в начале Lua-файла:

```lua
local PRE_ROLL_SEC = 2.0
```

Измените это значение, чтобы установить другое количество секунд до маркера или начала региона.
