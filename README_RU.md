# Play 2s Before Next Marker or Region

[English](README.md) · **Русский**

Перемещает курсор на две секунды раньше следующего маркера или начала региона.

## Работа скрипта

- При остановленном транспорте использует позицию курсора редактирования и запускает воспроизведение.
- Во время воспроизведения, паузы или записи ориентируется на позицию воспроизведения и выполняет переход без явной остановки транспорта.
- Рассматривает маркеры и начала регионов справа от исходной позиции.
- Если соответствующего маркера или региона нет, выводит сообщение.

## Настройка

Константа `PRE_ROLL_SEC` в начале Lua-файла определяет отступ в секундах. Значение по умолчанию — `2.0`.

## Установка

### Через ReaPack

Добавьте [каталог Patch34 ReaPack](https://raw.githubusercontent.com/patch-34/patch34-reapack/main/index.xml) через **Extensions → ReaPack → Import repositories…**. В **Extensions → ReaPack → Browse packages** найдите пакет **Play 2s Before Next Marker or Region**, установите его и синхронизируйте пакеты.

### Вручную

1. Скопируйте `Play_2s_Before_Next_Marker_Or_Region.lua` в каталог `Scripts` ресурсов REAPER (см. **Options → Show REAPER resource path**).
2. Откройте **Actions → Show action list → New action → Load ReaScript** и выберите Lua-файл.
3. Запустите действие или назначьте сочетание клавиш.

При ручном обновлении заменяйте файл по прежнему пути. При изменении имени файла действие может потребоваться зарегистрировать заново.
